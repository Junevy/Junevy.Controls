## TitleAssist 新增 TitleWidth 固定宽度

- 需求：表单式页面 TitlePlacement=Left 时标题长短不一导致视觉不齐；用户确认设计——四方位统一生效 + Left 方位标题右对齐贴合输入框。
- 实现：`TitleAssist` 注册 `TitleWidthProperty`（RegisterAttached，double，默认 NaN）+ Get/Set；TextBox.xaml / ComboBox.xaml 各 4 个标题呈现器加 `Width="{TemplateBinding atc:TitleAssist.TitleWidth}"`（NaN 即 Auto，无回归）；TitleLeft 呈现器加 `TextBlock.TextAlignment="Right"`（附加属性继承送达 ContentPresenter 内部 TextBlock，自动宽度下无视觉影响）。栅格列 0/2 为 Auto、列 1 为 Star——固定宽度经 Auto 列撑开，天然实现输入框整列对齐（间距 = 宽度 + 4 DIP margin）。
- 探针（RenderProbe4，15/15 PASS）：固定宽度 ActualWidth==120（TextBox/ComboBox、Left/Top）；NaN 回归（默认值 NaN + 呈现器自适应 41.6）；两输入框左缘同位 144（=控件左 20+120+4）、自动宽度用例 65.6 不受影响；TextAlignment==Right 经继承链生效；像素断言标题墨迹右缘距呈现器右缘 0.5 DIP。
- 探针新坑两个：`Control.ApplyTemplate()` 在模板**已应用**时返回 false——`!ApplyTemplate()` 判断会把正常情况当失败，必须忽略返回值直接 FindName；探针工程在 `.workbuddy/tmp/X/` 时 ProjectReference 相对路径是 `..\..\\<sln>.csproj`（三层）不是两层。
- Showcase 输入页新增固定宽度表单对齐演示（用户名/电子邮箱地址/部门，TitleWidth=110）；README TitleAssist 加 TitleWidth 行 + 示例，并顺手修正了旧示例里 `Tag` 当占位符的残留（改 PlaceholderAssist）；CHANGELOG 新增「TextBox / ComboBox」条目。

## Button 悬停透明度反馈 + IsTextScaled 只缩小不放大

- 需求两项：1) 鲜艳背景（如红底）按钮悬停即变浅蓝（固定 Surface.Hover 底色）很灾难，改为降 opacity；2) 不设 Height 时默认字体非常大（IsTextScaled 默认 true，Viewbox 会放大填满按钮）。
- 用户三项决策（AskUserQuestion）：标准模板 hover=0.8 / pressed=0.65 整体降透明度（按压覆盖悬停）；NoBorderButtonTemplate 一并透明度化（原 hover=警告黄 / pressed=危险红）；IsTextScaled 默认 true 保留但只缩小不放大。
- 实现：Button.xaml 顶部新增 `Button.Hover/Pressed/Disabled.Opacity` 资源（0.8/0.65/0.5），三个模板触发器全部改为 Opacity（禁用保持置灰逻辑）；新增 internal `ShrinkBox`（Decorator，Controls/Button/ShrinkBox.cs）：测量取内容自然尺寸并把期望尺寸钳制在可用空间内，布局按自然尺寸居中 + RenderTransform(Origin 0.5,0.5) 视觉等比缩小，系数 = min(1, 两方向比值)——JvButtonTemplate 的 ScaledHost Viewbox 包进 ShrinkBox；IsTextScaled=false 仍走 NormalHost 完全固定。
- 探针 21/21 PASS：拉伸 400×260 / 显式 180×56 文字墨迹 95×47@4x 与参考基准完全一致（修复前会放大填满容器）；挤压 Width=44 等比缩小（宽高比 2.03 vs 2.02）；DesiredSize Δ=0；三模板触发器结构断言；禁用实时生效（Opacity=0.5 + 底色/描边重置）。
- 探针新坑（重要）：Pbgra32 是**预乘 alpha**——按钮边缘半透明过渡像素（白×低alpha）按亮度阈值会被误判为暗墨迹，bbox 永远等于按钮轮廓；墨迹检测必须只统计 alpha≥250 像素。另外浅色主题 Border.Default 是深色，1px 描边同样污染 bbox，测试按钮需设 BorderThickness=0。G 断言一度漏设 IsEnabled=false（误写 IsDefault）。
- .sln 引用三个已删除项目（Junevy.Controls.Test / Tests / Samples.ToolboxDemo）导致 MSB3202，`dotnet build sln` 失败；直接 build 库 csproj + Showcase csproj 可行。sln 清理待定。
- README Button 章节补悬停反馈与 IsTextScaled 说明（此前未收录）；CHANGELOG 新增 Button 条目；Samples 按钮页删 IsTextScaled=False workaround。现累计四轮未提交（等用户指示）。

## 悬停/按压透明度方案推广至其余可交互控件（第二轮，用户指示"一起优化"）

- 全量排查 17 个模板文件约 50 处 Surface.Hover/Pressed 消费点，按表面性质分三类并经用户确认：**A 类**（背景 TemplateBinding 暴露给用户的按钮/卡片：CardButton、ToolBarItem、ToolboxItem 触发按钮、ToolItem）转透明度；**B 类**（内部图标小按钮：MessageBar/ProgressBarWindow 关闭按钮、ImageViewer 工具栏按钮、DialogWindow 标题栏按钮、ToggleButton Expander 展开按钮、DatePicker 日历导航/头部/下拉按钮）转透明度；**C 类**（中性表面列表/菜单/日历单元格：MenuBar、ContextMenu、TabMenu、SideMenu、TreeMenu、ListBox/ListView/DataGrid 行与表头、DatePicker 日期/月单元格、GroupBox/ExpanderPanel 标题行）**保留灰底**——灰底是行项正确 affordance，降透明度会让行内容变淡、悬停感知几乎消失。
