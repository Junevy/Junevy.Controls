## 第五轮：Showcase 分类展示程序（Samples/Junevy.Controls.Showcase）

- 应用户要求开发展示程序：按 8 类分页展示全部控件（按钮/输入/数据/文本状态/通知/布局/菜单/窗口图像），AppBar 展示默认状态（一个程序只能存在一个），数据控件填充虚拟数据（SampleData 单例），附加属性全部演示（Icon/TitleAssist/PlaceholderAssist/DataGridAssist.EmptyText/DatePickerAssist/ExpanderBehavior + WindowChrome.IsHitTestVisibleInChrome）。
- 关键发现 1：`Border.CornerRadius` 每实例特性语法（`<jv:Button Border.CornerRadius="16">`）不通过标记编译（MC3015，Border 无附加模式访问器），库模板只是 `{TemplateBinding Border.CornerRadius}` 读取；正确做法是 Style Setter（`BasedOn={StaticResource {x:Type jv:Button}}` + `<Setter Property="Border.CornerRadius" Value="16"/>`）。README 原文档写的是非编译语法，已修正。
- 关键发现 2：`jv:Button.IsTextScaled` 默认 true，JvButtonTemplate 的 Viewbox（ScaledHost 内含 Star 列）把测量的可用空间传下去，导致 DesiredSize 填满容器（600x200 容器中实测 desired=320x200；IsTextScaled=False 时 49.6x28.8）。与设计注释「按钮自适应内容大小时缩放系数为 1」矛盾。Showcase 中 6 个页面用页级隐式样式 `IsTextScaled=False` 规避，留 1 个 True 演示；是否修库待用户决定。

## 第六轮：TextBox 内部命令按钮（CommandButton）

- 需求（用户明确提出）：TextBox 内部加一个可绑定 Command 的按钮，bool 控制显隐；清空按钮显示时该按钮隐藏。设计经用户确认：新增 `CommandButtonContent`（object）承载内容 + `CommandButtonCommandParameter`（object）传参。
- 新增 4 个 DP（注册在 jv:TextBox 上，原生 TextBox 实例可借用）：`ShowCommandButton`（bool 默认 false）、`CommandButtonCommand`（ICommand）、`CommandButtonCommandParameter`、`CommandButtonContent`。模板部件 `PART_CommandButton`（bt:Button 复用 TextBoxCloseButtonStyle，宽 26 与清空按钮一致，Focusable=False）。
- **互斥实现**：默认模板 MultiTrigger——仅「ShowCommandButton=true 且 ShowClear=false」时命令按钮 Visible，元素默认 Collapsed；ShowClear=true 时清空按钮显示、命令按钮保持隐藏。Register 注册的 DP 在模板 Trigger/Condition 里用 `local:TextBox.Xxx` 附加语法引用可行（与样式 Setter 同理）。
- 探针经验（重要）：离屏环境下手动 `new ButtonAutomationPeer(btn)` 是分离 peer，未接入事件源，`IsEnabled()` 返回 false → `IInvokeProvider.Invoke()` **静默跳过**（不抛异常、Click 不触发），不能用于点击断言；且 `IInvokeProvider` 是显式接口实现，须强转后调用。改为断言 Command/CommandParameter 绑定送达按钮 + 经按钮自身属性执行命令；「CanExecute=false → IsEnabled=false」通过即证明 ButtonBase 命令管线激活。`ButtonAutomationPeer` 构造参数是 `Button`（非 ButtonBase）。
- 沙箱文件坑补充：`Remove-Item` 在沙箱 shim 下可能静默失效或报管道绑定错误（同批命令时而成功时而失败），改用 `[System.IO.File]::Delete` / `[System.IO.Directory]::EnumerateFiles` 可靠。
