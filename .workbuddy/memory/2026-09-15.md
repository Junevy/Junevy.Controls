# 2026-09-15

## ToggleButton 开关尺寸与视觉重构
- 移除 `SwitchWidth` / `SwitchHeight`（破坏性变更），新增单一 `SwitchSize`（高度，默认 20），轨道宽度按 2:1 自动推导，消除宽高比例失衡导致的变形。
- `SwitchToggleButton_Radius` / `SwitchToggleButton_Rect` 两个模板由"左右两半填充"重构为"轨道 + 滑块"：滑块边长 = SwitchSize − 4，滑动动画（200ms QuadraticEase EaseOut）在控件代码（OnChecked/OnUnchecked/OnApplyTemplate/OnSwitchSizeChanged）中驱动 `PART_Thumb` 的 `TranslateTransform`，行程 = SwitchSize。
- 几何推导通过只读依赖属性（TrackWidth/TrackCornerRadius/ThumbSize/ThumbCornerRadius/ThumbTravel，DependencyPropertyKey）暴露给模板，构造函数中主动初始化一次（默认值不触发变更回调）。
- 圆角数学：胶囊轨道圆角 = S/2，滑块圆角 = (S−4)/2 = 轨道圆角 − 2（内缩量一致）；矩形模板滑块圆角固定 2 = 外圆角 4 − 内缩 2。
- 移除 DefaultToggleButton 中已无消费者的 `Border.CornerRadius` 设置。
- README（属性表、示例、jv: 前缀说明）、CHANGELOG 已同步更新。
- 验证：编译 0 警告 0 错误（net48/net8.0），测试 100/101 通过；`Button_DefaultMinimumHeight_Is20` 为存量失败（基线同样失败，Button 样式 MinHeight=10 vs 测试期望 20），与本次改动无关，已向用户报告。
- 注意：`Junevy.Controls.sln` 引用了不存在的 `Junevy.Controls.Test` 项目，`dotnet build sln` 会失败，需单独构建 csproj 或修复 sln（待用户决定）。
