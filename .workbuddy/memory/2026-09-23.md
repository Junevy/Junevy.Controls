## DataGrid 控件模板重构为官方宿主结构（严重缺陷修复）
- 用户怀疑成立：旧模板在 ScrollViewer 内容 Grid 中直接声明 `<DataGridRowsPresenter x:Name="PART_RowsPresenter"/>` 且无 ItemsPresenter。经对照 dotnet/wpf 官方源码确认：模板里直接声明的面板 IsItemsHost=false，DataGrid 不会向其生成行；行宿主必须由 ItemsPresenter 从 DataGrid 默认 ItemsPanel（静态构造函数注册的 DataGridRowsPresenter 工厂，运行时命名 PART_RowsPresenter）实例化，经 DataGridRowsPresenter.OnIsItemsHostChanged 挂为 InternalItemsHost。
- DataGrid 内部滚动接线：EnsureInternalScrollControls 从 ItemsHost 向上 FindVisualParent<ScrollContentPresenter>/<ScrollViewer>；HorizontalScrollOffset 绑定 ScrollViewer.ContentHorizontalOffset 同步列头水平偏移。因此行宿主必须处于 ScrollContentPresenter 之内。
- 修复后结构（对齐官方 Aero2.NormalColor.xaml）：Border → ScrollViewer(Focusable=false，自定义 Template：3x3 Grid 放全选按钮/PART_ColumnHeadersPresenter/PART_ScrollContentPresenter/PART_VerticalScrollBar/PART_HorizontalScrollBar) → Content=ItemsPresenter。列头放 ScrollViewer 模板内才能垂直滚动时固定。
- 官方细节：ScrollViewer 模板内 TemplatedParent 是 ScrollViewer，引用 DataGrid 属性须用 AncestorType；横向滚动条首列宽度绑 NonFrozenColumnsViewportHorizontalOffset（冻结列对齐）；官方有 IsGrouping 且 !IsVirtualizingWhenGrouping → CanContentScroll=false 的 MultiTrigger（已补入样式）。
- 验证：.workbuddy/tmp/DataGridProbe/（net8 探针，RenderTargetBitmap @4x）全部 PASS——行生成 1000 项仅 9 容器、宿主链命名/IsItemsHost/祖先关系正确、VerticalOffset=500 精确、Recycling 滚动后 10 容器、列头垂直固定、水平滚动 120 后列头与单元格 X Δ=0.00、空态提示（绑定改 AncestorType 后）可见。主库双目标编译 0 错误。文档（CHANGELOG/README）已更新。
